# firebase

Adaptateurs Firestore (`firebase-admin`) : le port `IWorkflowStateRepository` de l'assistant (collection `workflow-states`) et le port `InteractionHistoryRepository` de `@org/ai`, l'historique des échanges avec Claude (collection `ai-interaction-histories`).

- Tests : `npx nx vite:test firebase`
- Lint : `npx nx lint firebase`
- Types : `npx nx typecheck firebase`
